Line charts show change over time. Series colours come in order from `chart-1` to `chart-8`; the first series gets a 14% area fill. Gridlines use `chart-grid`, three at most, with value labels in `ink-muted` `caption` size at left; the last point is marked and labelled with its value. Lines are 2.5px with round caps.

The consumer provides series (name, values), a time axis and an accessible `aria-label` that states the headline trend. Always add a legend or direct labels; never color alone.
