Buttons trigger one action. Use `re-btn--primary` (System-blue `accent`) once per window; the default white (`surface-1`) button for secondary actions; `re-btn--quiet` in toolbars; `re-btn--danger` only for destructive steps that also ask to confirm.

The consumer provides a verb label of one to three words in sentence case and an optional icon. Height comes from `control-sm`, `control-md` or `control-lg`; radius `radius-sm`. Pressed state scales to .97 with the standard ease.

- Don't put two primary buttons together. Text on `accent` is always `on-accent`.
