Depth has five levels, each an ambient shadow plus a 0.5px contact edge, so stacked surfaces read as layers even in dark themes: `shadow-1` buttons and cards, `shadow-2` widgets and charts, `shadow-3` tiled windows, sidebar and dock, `shadow-4` menus, popovers, palette and toasts, `shadow-5` the focused window and anything being dragged. Glass surfaces add an inset 1px `glass-edge` highlight at the top so the pane catches light. In High contrast every level becomes a solid black outline. Moving up a level on hover is the only shadow animation (`dur-base`, `ease-standard`).
