Everything that changes state moves, and nothing moves for decoration. Use `dur-fast` with `ease-standard` for hover, press, focus and colour; `dur-base` for switches, menus, tabs and theme changes (a theme change crossfades all surfaces at once); `dur-slow` for windows moving to a new tile, sheets and the palette; `ease-spring` only where a thing responds to the user (dock hover, Pip reacting, a badge appearing); `ease-exit` for anything leaving. Ambient loops (Pip breathing, the island pulse) use `dur-ambient` and nothing else loops. Under `prefers-reduced-motion` every duration becomes 1ms and loops stop; fades remain.
