A window holds one view (Today, Mail, Notes, Canvas, Browser, Pip, and so on). It has a `radius-win` shape, a 52px unified titlebar on `glass-strong` with traffic-light controls at left, the view title centred and actions at right, and a `surface-1` body.

Focus: the active window gets a solid 2px `focus` border (`focus-border`) and `shadow-window`; others have no border, `shadow-window-rest`, and their traffic lights turn gray. The consumer provides title, actions and body.
