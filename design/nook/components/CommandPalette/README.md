The palette (Win+Space, and Ctrl+K inside a window) opens views, moves windows, runs actions or asks Pip. It is a `glass-strong` sheet of `radius-xl` at `z-palette`, in the upper third of the screen with a 20px input. The selected row is solid `accent` with `on-accent` text. The consumer provides groups (Views, Windows, Actions, Ask) and each row's label, meta and shortcut. Esc closes, arrows move, Enter runs.
