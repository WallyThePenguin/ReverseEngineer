Nook ships six themes, set with `data-theme` on the root: Light (default), Dark, Midnight (true black for OLED), Dusk (warm charcoal, amber accent), Paper (cream reading mode, sienna accent) and High contrast (7:1 text, black outlines, opaque chrome). Every token has a value in every theme, so components need no per-theme rules. Offer the picker in Settings and let the system setting choose between Light and Dark by default; a theme change crossfades over `dur-base`.
