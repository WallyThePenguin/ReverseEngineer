Pip, Nook's agent and mascot, in five states: `pip-idle.svg`, `pip-listening.svg`, `pip-thinking.svg`, `pip-happy.svg`, `pip-asleep.svg`. Use the inline SVG from the Pip component when Pip should move; use these files for icons, notifications, onboarding art and the website. Colours are baked to the Light theme (ice-blue body, dark eyes, soft blue glow). Never redraw, recolour, outline or add anything to Pip; keep a margin of one eighth of its width; minimum size 20px.
